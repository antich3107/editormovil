# Prueba manual M2

- [ ] Crear un proyecto con 2 escenas y un guion.
- [ ] Importar 2 imágenes distintas y un audio pequeño.
- [ ] Asignar una imagen a cada escena y seleccionar el audio como narración.
- [ ] Crear ZIP completo; verificar que se descarga `*_Editor_M2.zip`.
- [ ] En Windows, iniciar `INICIAR_TRANSFERENCIA_WIFI.bat` y abrir la IP desde el Android conectado a la misma Wi-Fi.
- [ ] Subir ZIP; comprobar nombre del proyecto, número de escenas y recursos.
- [ ] Iniciar render y comprobar que el MP4 aparece en `Proyectos_importados/<proyecto>/`.
- [ ] Probar después con un vídeo corto mezclado con una imagen.
